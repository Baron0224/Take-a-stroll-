# 散步小程序

一个帮助用户从当前位置开始散步的微信小程序原型。

## 项目结构

- `miniprogram/`：微信小程序代码
- `demo/`：可在浏览器中体验的交互原型
- `项目说明.md`：产品想法、功能范围和当前进度

## 当前进度

目前包含距离/时长选择、定位起点、随机步行路线规划、路线预览、收藏与本机散步记录。路线规划使用高德微信小程序 SDK 返回的道路折线。

实时导航、语音提示、偏航重规划和基于真实 GPS 轨迹的距离/时长记录尚未实现；个人数据目前保存在当前设备。

## 导入微信开发者工具

在微信开发者工具中导入 `miniprogram/` 目录。首次运行前：

1. 将 `miniprogram/utils/amap-config.example.js` 复制为 `amap-config.js`。
2. 在本地的 `amap-config.js` 中填写高德开放平台的“微信小程序”Key。
3. 在微信公众平台服务器域名的 `request` 合法域名中添加 `https://restapi.amap.com`。

本机 Key 配置和微信开发者工具私有配置已加入 `.gitignore`，不会提交到仓库。
